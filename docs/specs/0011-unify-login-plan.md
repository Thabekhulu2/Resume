# Implementation Plan: Unify Recruiter and Candidate Login

**Spec:** [0011-unify-login.md](./0011-unify-login.md)
**Ticket:** Closes #22
**Status:** Implemented, verified against local stack — 2026-09-04. Awaiting Gate 2 (commit) approval.

## Phase 1: Auth helper

- [x] `frontend/src/lib/auth.tsx`: change `signIn`'s return type to `Promise<{ error: string | null; role?: UserRole }>` — after `signInWithPassword` succeeds, call `resolveRole(data.user.id)` (already exported) and return it alongside `error: null`, so callers don't need a second round-trip or rely on the async context state (same race class as ticket #21).

## Phase 2: Unify the login page

- [x] `frontend/src/routes/login.tsx`: on submit, use the `role` returned by `signIn`; `navigate({ to: role === 'candidate' ? '/apply' : '/' })`. Change heading/copy from "Recruitment Team Login" to "Log In" / "Sign in to continue."
- [x] Delete `frontend/src/routes/candidate/login.tsx`.
- [x] `frontend/src/routes/candidate/signup.tsx`: "Log in" link target `/candidate/login` -> `/login`.

## Phase 3: Redirect targets

- [x] `frontend/src/routes/_authenticated.tsx`: wrong-role redirect `/candidate/login` -> `/login`.
- [x] `frontend/src/routes/_candidateAuth.tsx`: no-session redirect `/candidate/login` -> `/login`.
- [x] `frontend/src/routes/__root.tsx`: `PUBLIC_PATHS` drops `/candidate/login`; `Header.handleLogout` navigates to `/login` unconditionally (drop the `role === 'candidate' ? ... : ...` branch).
- [x] Regenerate `frontend/src/routeTree.gen.ts` (TanStack Router Vite plugin, via `npx tsc --build` / dev server hot-reload — verify it drops the `candidate/login` route entry).
